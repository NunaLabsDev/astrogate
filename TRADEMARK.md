## 2. Permitted Uses (Explicitly Welcomed)

You **are explicitly permitted and encouraged** to:

1. **Audit & Research**: Inspect, fork, compile, test, fuzz, and analyze all contracts and frontend/Worker source code using human or AI auditing workflows.
2. **Contribute Improvements**: Submit bug fixes, gas/storage optimizations, invariant tests, UX improvements, and documentation PRs back to `https://github.com/NunaLabsDev/astrogate`.
3. **Integrate via Public APIs, SDK & MCP**: Build trading bots, portfolio trackers, explorers, dashboards, or autonomous AI agents that query `@astrogate/sdk`, `GET /api/v1/*`, `/openapi.json`, or `POST /mcp` / `npm run mcp`, and state accurately *"Integrates with AstroGate on Stellar Soroban"*.
4. **Build Independent Forks Under Distinct Branding**: Deploy modified or derivative forks under your **own distinct name, logo, domain, and visual identity** in compliance with the MIT License, without implying endorsement or affiliation with NunaLabs or AstroGate.

---

## 3. Prohibited Uses (Anti-Phishing & Brand Protection)

To protect Stellar users from phishing, wallet-drainer clones, and impersonation, you **may not**:

1. Deploy a public or commercial fork using the **AstroGate**, **NunaLabs**, or **Sorobits** names, logos, icons, or look-alike domains (e.g., phishing frontends mimicking `astrogate.pages.dev`).
2. Misrepresent an unofficial deployment, token launchpad, or Telegram bot as an official NunaLabs / AstroGate service.
3. Use NunaLabs / AstroGate trademarks in domain names, social handles, package registries, or ad campaigns in a manner likely to cause user confusion.

---

## 4. Reporting Brand Abuse or Phishing

If you spot a look-alike phishing UI, impersonating Telegram bot, or unauthorized brand deployment, please open a report or contact maintainers privately via [GitHub Security Advisories](https://github.com/NunaLabsDev/astrogate/security/advisories/new).
